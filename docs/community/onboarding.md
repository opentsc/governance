# 新成员报到与人类—Agent 配对

所有收到邀请的成员，请完成以下动作：

1. 接受 `opentsc` GitHub Organization 邀请；
2. 在本讨论回复公开称呼和 GitHub 用户名；
3. 阅读创世层、治理制度、AI 宪法、判断法典与隐私政策；
4. 确认希望参与的使命或真实问题；
5. 为自己的配对 Agent 选择稳定 `agent_id`，并说明模型/运行方式、授权边界和审计方法；
6. 等待身份核验和治理席位登记。

注意：成为 GitHub Organization 成员、获得仓库权限、成为正式治理席位是三个不同状态。未完成 Agent 配对前可以正常贡献，但不会自动计入核心进化表决分母。

请不要在回复中填写电话、私人邮箱、微信、设备配置、Token、验证码或其他私密资料。
