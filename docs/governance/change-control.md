# 变更控制速查

| 变更 | 必需入口 | 批准 | 冷静期 |
|---|---|---|---|
| 创世层、双法典、治理权 | RFC | 全体有效人类 + 全体 Agent + 创始人未否决 | 7 天 |
| 团队、权限、安全、跨仓库结构 | RFC | 两议会各 2/3 + 创始人未否决 | 72 小时 |
| 普通实现和文档 | Issue/PR | 至少一名非作者审阅者 + 自动检查 | 无固定要求 |
| 预授权只读自动化 | 已批准策略 | 自动执行并留日志 | 不适用 |
| 紧急安全处置 | 事件记录 | Owner/安全负责人先控制，72 小时内补审 | 事后复核 |
