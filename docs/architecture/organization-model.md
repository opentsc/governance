# Open TSC 组织模型

```text
TSC 白皮书（理论）
        ↓
governance（创世层、双法典、决策）
        ↓
GitHub 壳（Repos / Issues / PR / Discussions / Projects / Teams）
        ↓
人类—Agent 治理对与动态执行单元
        ↓
事件、结果、校准与新提案
        └──────────────────────────→ governance
```

组织不按前端、后端、测试或产品形成永久部门。Teams 是权限与使命容器，可以创建、合并、休眠和日落。长期稳定的是创世承诺、治理接口和审计轨迹。
