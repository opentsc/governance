# 仓库生命周期与命名

## 状态

`proposal → sandbox → incubator → active → maintenance → archived`。

进入 `active` 前必须有明确使命、Owner、README、许可证/保密说明、安全入口和维护策略。连续 90 天无活动且无明确维护承诺的仓库进入维护或归档评审。

## 分类

- `governance`：治理与公共制度。
- `infrastructure`：组织和平台基础设施。
- `research`：研究、实验和证据。
- `shared`：跨项目复用资产。
- `products`：对用户交付的产品。
- `sandbox` / `incubator`：低成本探索和孵化。

## 命名

仓库使用小写英文和连字符，名字表达长期使命，不使用人员姓名、临时组织架构或版本号。重大重命名需提供迁移链接和兼容期。
