# AI 行动分级

| 等级 | 示例 | 默认规则 |
|---|---|---|
| A0 只读 | 扫描、搜索、报告、验证 | 可自动，必须尊重数据边界 |
| A1 草案 | 创建本地草案、Issue、分支、Draft PR | 可在授权范围内自动，必须标明 Agent |
| A2 可逆写入 | 标签、分配、普通文档 PR | 需要预授权、日志和撤销方法 |
| A3 高影响写入 | 合并、发布、权限、安全、团队、仓库设置 | 必须人工批准 |
| A4 不可逆/敏感 | 删除仓库、泄露资料、提权、隐藏审计 | 禁止 Agent 单独执行 |

Agent 每次行动必须选择等级。无法判断等级时按更高风险处理。
