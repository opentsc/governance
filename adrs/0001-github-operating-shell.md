# ADR-0001：以 Git 仓库保存魂，以 GitHub 作为当前运行壳

- 状态：accepted（启动授权）
- 日期：2026-08-02

## 决策

治理契约、决策和可迁移记录使用开放文件格式保存在 Git 仓库中；GitHub 提供当前协作、权限、论坛、Project 和自动化能力。

## 理由

这同时满足 GitHub Driven 与魂壳分离：GitHub 是强大的运行界面，但组织身份不被单一供应商锁定。

## 后果

- 权威内容必须能通过 Git 导出。
- Discussions 和 Project 是讨论与运行视图，不能成为唯一记录。
- 组织基础设施需要定期导出和恢复演练。
