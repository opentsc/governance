# Open TSC Wiki

欢迎来到 Open TSC 知识导航。Wiki 用于帮助成员快速找到入口和理解日常流程；权威治理文本始终以 [`governance`](https://github.com/opentsc/governance) 仓库 `main` 分支为准。

- [TSC 白皮书](https://github.com/opentsc/tsc)

## 新成员第一天

1. 接受 GitHub Organization 邀请。
2. 阅读创世层、治理制度、AI 宪法和判断法典。
3. 在论坛的成员报到讨论中留言。
4. 确认自己的公开 GitHub 身份和私密资料边界。
5. 登记配对 Agent；未完成配对前可以贡献，但不形成完整核心治理席位。
6. 从 Project 或仓库 Issue 中选择一个边界清楚的任务。

## 日常协作

小问题使用 Issue，可探索问题使用 Discussion，可版本化变更使用 Pull Request，重大组织改革使用 RFC，已经做出的长期架构选择使用 ADR。
