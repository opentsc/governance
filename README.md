# Open TSC 治理中心

> 状态：**启动期运行版本**。组织已经开始运行；创世层与双法典在完整的人类—Agent 治理席位建立后进行首次正式追认。

这里是 [Open TSC](https://github.com/opentsc) 的公开治理中心，也是组织“魂”的根入口。Open TSC 以中文为权威语言，通过 GitHub 让组织规则、判断标准、提案、决策与演化过程可阅读、可审阅、可追溯、可迁移。

- [创世层](GENESIS.md)：为什么存在、不可跨越的边界与身份连续性。
- [治理制度](GOVERNANCE.md)：一人一 Agent、双议会、创始人否决权与变更门槛。
- [AI 宪法](AI-CONSTITUTION.md)：AI 的授权、禁止事项、人工批准与审计要求。
- [判断法典](JUDGMENT-CODEX.md)：组织如何判断“好、可信、值得行动”。
- [持续演化队列](ROADMAP.md)：当前正在解决的组织问题。
- [成员制度](MEMBERS.md)：治理席位、身份状态与隐私边界。
- [RFC](rfcs/README.md)：重大改革提案。
- [ADR](adrs/README.md)：已经作出的架构决策。
- [组织论坛](https://github.com/opentsc/governance/discussions)：公告、讨论、问答、想法与 RFC 审议。

- [组织演化看板](https://github.com/orgs/opentsc/projects)：跨仓库工作与治理进展。

## 仓库分工

| 仓库 | 定位 |
|---|---|
| [`tsc`](https://github.com/opentsc/tsc) | TSC 3.0/3.5 白皮书，理论之魂 |
| [`opentsc`](https://github.com/opentsc/opentsc) | 当前软件实现，可替换的壳 |
| [`governance`](https://github.com/opentsc/governance) | 创世层、双法典、治理记录与公共议事 |
| [`.github`](https://github.com/opentsc/.github) | 组织主页和默认社区健康文件 |
| `organization-infrastructure` | 私有的组织即代码、审计与运行手册 |

## 基本工作流

```text
观察与证据
→ Issue / Discussion
→ 提案或 RFC
→ 人类与 Agent 分别审议
→ Pull Request
→ 按变更等级批准
→ 合并与发布
→ 验证现实结果
→ 记录校准
```

## 语言与隐私

中文版本具有最高解释权。英文可以存在，但只能作为翻译。公开仓库不得保存电话号码、私人邮箱、微信、设备清单、投入时间或其他不必要的个人资料；完整规则见[语言政策](policies/language.md)与[隐私政策](policies/privacy.md)。
