# RFC-0000：标题

- 状态：draft
- 作者：GitHub 用户名 / Agent ID
- 创建时间：YYYY-MM-DD
- 影响范围：治理 / 权限 / 安全 / 仓库 / 自动化 / 其他
- Discussion：链接
- Pull Request：链接

## 问题与证据

说明当前发生了什么、证据来自哪里、为什么值得改变。

## 提案

给出边界清楚、可被实现和审阅的规则或结构。

## 替代方案

至少列出“不改变”以及一个其他可行方案，并说明取舍。

## 风险与隐私

列出安全、权限、隐私、成员权利和长期维护风险。

## 验证与失败信号

说明如何证明提案有效、何时判定失败。

## 回滚与迁移

说明如何恢复，以及已有数据和成员如何迁移。

## 投票记录

分别记录人类议会、Agent 议会与创始人确认/否决结果。每票必须可追溯。
